# 무무투표 — 학교 선거를 링크 하나로

> 태블릿 한 대로도, 학생들 각자 기기로도. 초등 교실을 위한 선거 앱.

**🔗 https://mumuvote.vercel.app**

---

## 한 줄 소개

학급·전교학생회 선거를 만들고, 후보 공약을 살펴보고, 그 자리에서 투표하고 집계까지 끝내는 웹앱입니다. 설치도 회원가입도 없이 링크만 있으면 됩니다.

---

## 왜 만들었나

초등학교 선거는 매번 이렇게 돌아갑니다.

- 종이에 후보 이름 적어 오려서 투표용지 만들기
- 칠판에 '正' 자 그려가며 개표
- 반이 여러 개면 종이 쪽지를 모아 합산
- 공약은 교실 뒤에 붙여둔 포스터로 끝

준비에 한 시간, 개표에 또 한 시간. 정작 **아이들이 공약을 읽고 고민하는 시간**은 제일 적었습니다.

그래서 "선생님은 3분 만에 선거를 열고, 아이들은 공약을 충분히 보고 투표하는" 도구를 만들었습니다.

---

## 이렇게 씁니다

### 1. 선거 만들기 (선생님, 3분)

선거 이름 · 4자리 접속 코드 · 투표 방식을 정하고, **− / +** 로 후보 수를 지정한 뒤 이름·슬로건·공약을 채웁니다. **포스터와 공약은 사진 파일로 바로 업로드**할 수 있어서, 아이들이 그린 손포스터를 찍어 올리면 그대로 화면에 뜹니다.

> 📷 `03-선거등록.png`

### 2. 명단 등록

반 이름과 투표인단을 `학번 이름` 형식으로 한 줄씩 붙여넣습니다. (예: `6101 김민준`)

### 3. 후보 살펴보기 — 방식도 함께 설명

후보 카드를 누르면 **왼쪽에 포스터, 오른쪽에 공약**이 크게 뜹니다. 화면 위에는 **투표 방식이 어떻게 계산되는지** 설명이 붙어 있어서, 아이들이 "왜 3등까지 고르지?"를 이해한 상태로 투표합니다.

> 📷 `04-후보목록과방식안내.png`, `05-후보상세.png`

**순위투표**는 1등 3점 · 2등 2점 · 3등 1점으로 환산해 모두 더합니다. 1등을 적게 받아도 2·3등을 골고루 받으면 순위가 올라갈 수 있어, "한 명만 찍고 끝"이 아니라 **여러 후보의 공약을 두루 보게 되는** 효과가 있습니다. 선거 교육용으로 쓰기 좋습니다. (단순 다수결이 필요하면 **단순 선택** 모드를 쓰면 됩니다.)

### 4. 투표 — 두 가지 방식 중 선택

**🖥️ 키오스크 모드** — 태블릿 한 대를 돌려가며 씁니다. 명단 순서대로 이름이 뜨고, 한 명이 끝나면 자동으로 다음 사람 차례로 넘어갑니다. 기기가 한 대뿐인 교실용.

**📱 개별 투표 모드** — 선생님이 **비밀 링크**를 공유하면 학생들이 각자 자기 태블릿으로 들어와 동시에 투표합니다. 명단에서 자기 이름을 누르고 **학번을 입력해야** 진행되므로, 실수로 남의 이름을 눌러 투표가 날아가는 사고를 막습니다. 이미 투표한 이름은 실시간으로 잠깁니다.

> 📷 `06-개별투표_이름선택.png`, `07-학번확인.png`, `08-순위투표_1등고르기.png`

### 5. 결과 발표 — 3 · 2 · 1

개표가 끝나면 결과를 바로 띄우지 않습니다. **[🥁 결과 발표하기]** 를 누르면 전체 화면으로 **3 → 2 → 1 → 두구두구** 카운트다운이 흐르고, 팡파레와 함께 색종이가 흩날리며 결과가 공개됩니다. 교실이 술렁이는 그 순간을 위한 연출입니다. (급할 땐 "바로 보기"로 건너뛸 수 있어요.)

반별 집계가 자동으로 나오고, **체크박스로 원하는 반만 골라 합산**할 수 있습니다.

> 📷 `09-결과발표대기.png`, `10-카운트다운.png`, `11-결과공개.png`

## 특징

| | |
|---|---|
| **설치 없음** | 링크만 열면 끝. 앱스토어·회원가입·로그인 없음 |
| **1인 1표 보장** | 투표를 학생별 문서로 저장해, 25명이 동시에 눌러도 표가 유실되지 않음 |
| **실수 방지** | 학번 확인 + 중복 투표 자동 잠금 |
| **방식 설명 내장** | 순위투표 점수 계산을 학생 눈높이로 화면에 안내 |
| **반별 → 전교 합산** | 반마다 따로 투표하고 원하는 반만 골라 합산 |
| **공약 중심 화면** | 후보를 누르면 왼쪽 포스터·오른쪽 공약 2단으로 크게 |
| **발표 연출** | 3·2·1 카운트다운 + 드럼롤 + 색종이 |
| **효과음 & 음소거** | 클릭음·완료음·팡파레, 교실용 음소거 토글 |
| **슈퍼 관리자** | 선거 목록·접속 코드·진행 현황 확인, 선거/반 삭제 |
| **넓은 화면 우선** | 태블릿·PC에 최적화, 휴대폰에서도 안 깨짐 |

## 만든 방식

- React + Vite / Tailwind CSS
- Firebase Firestore (실시간 공유·집계) + Storage (포스터·공약 이미지)
- Vercel 배포
- 기획부터 구현까지 **Claude Code로 바이브코딩**

실제 공개수업에서 쓰려고 만들었고, 수업을 준비하면서 필요한 기능을 하나씩 붙였습니다. 처음엔 태블릿 한 대짜리 키오스크 앱이었는데 "그날은 애들이 각자 기기로 하면 좋겠다"에서 개별 투표 모드가 나왔고, "실수로 눌리면 어쩌지"에서 학번 확인이, "발표할 때 긴장감이 있으면 좋겠다"에서 카운트다운이 나왔습니다. 교실에서 쓰다 보면 필요한 게 계속 보이더군요.
